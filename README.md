学习鸿蒙复刻了小红书界面，都是编辑的死数据，用以学习鸿蒙界面编程。
技术实现要点（用到的鸿蒙组件、布局难点）
1.	布局组件：用了Column、Row完成垂直和水平布局；Stack完成了弹窗；用Flex组件完成了瀑布流；还用了Blank空白占位符
2.	滚动组件：用了Scroll组件实现滚动（比如顶部导航栏可以左右滑动，帖子等可以上下滑动）；用了List和ListItem做列表
3.	网格组件：我们用Grid，GridItem做了网格的布局
4.	轮播组件：用Swiper实现了详情页图片的轮播和滑动轮播/滑动容器
5.	文本组件：用了Text文本显示组件
6.	图片组件：用Image图片显示组件
7.	形状组件：Circle圆形组件（主要用于一些头像）
8.	分割线组件：Divider分割线组件（主要是弹窗选项分隔）
9.	输入组件：TextInput组件做了文本输入框（比如搜索页面、聊天页面）
10.	做了一些自定义接口：NoteItem做笔记数据模型；CommentItem做评论数据模型；ChatMessage做聊天消息模型；MessageItem做消息列表模型；QuickActionItem做快捷操作模型；SearchItem做搜索项模型；ChatParams做聊天页面参数
遇到的布局难点是：
1）	图片资源裁剪难以一步到位，截图因为没有明确的比例大小对照，导致图片除了1：1的整体比例，其他每张圆形图位置总是有点不一样。
2）	对齐：在嵌套完多层Row/Column后，很多原本对齐的组件发生了位置偏移，总是会有调这个位置，那个位置又变了的情况发生，没有总体调节布局的观念与经验。
3）	调节组件间的空隙：margin和padding之间总是想要一点点慢慢试，容易 搞反两者概念，第一个是外间距，是组件和其他的距离，另一个是内间距，组件内部的留白。
4）	预览器和真机界面有点不一样。
5）	瀑布流布局：首页和市集页要做那种左右两列、卡片高度不一样的效果。最开始不知道怎么做，后来问了好久的ai试错了很多次，最后用Flex套了两个Column去做实现了，左右列要对齐底部挺麻烦的，调了好久。
6）	有些页面上面有固定的搜索栏，下面要滚动，刚开始滑动的时候会出现卡顿或者改着改着固定栏又不固定了。后来把固定区域和可滚动区域分开写就好了。
